# Sesión de desarrollo — 2026-07-30

## Resumen

Se evolucionó `Dashboard → Grow → Flujo de marketing` para que la configuración
de los nodos distinga su **categoría funcional** del **título visible**. Esta
separación permitirá definir después qué datos puede editar cada categoría sin
perder las opciones generales del editor.

## Categoría y título

Cada nodo contiene ahora:

- `category`: tipo estable del módulo, mostrado en el Dashboard y no editable.
- `title`: texto personalizado que aparece dentro del nodo y sí puede editarse.

Ejemplos de categorías:

- Facebook Page
- Instagram
- TikTok
- Spotify
- Landing Page
- Recolección de datos
- Facebook Pixel
- Facebook ADS
- Descarga de QR
- Escanear QR
- Actualización de estado
- Almacenamiento SQL

Las instancias repetidas comparten categoría con su módulo original; por
ejemplo, `Landing Page (2)` pertenece a la categoría `Landing Page` pero conserva
un título independiente.

Los nodos creados desde el canvas utilizan inicialmente la categoría
`Nodo personalizado` y mantienen su título editable.

## Compatibilidad de datos

La normalización en `data/growFlow.js` conserva configuraciones anteriores:

- Si existe `title`, se utiliza directamente.
- Si una configuración antigua sólo contiene `label`, ese valor se migra como
  título.
- Si no existe ninguno, se usa el título predeterminado de la definición.

Esto evita perder títulos guardados antes de introducir las categorías.

## Controles que se conservan

La nueva estructura no elimina funciones existentes. Cada nodo mantiene, según
corresponda:

- Mostrar u ocultar mediante el botón de ojo.
- Eliminar mediante el botón de papelera.
- Color principal de cabecera.
- Subcolor para nodos de redes sociales.
- Imagen de icono subida o proporcionada mediante URL.
- Imagen de ejemplo para las categorías Landing Page.
- Posición modificada mediante arrastre en el canvas.
- Creación y eliminación visual de conexiones.

El antiguo listado inferior de conexiones permanece eliminado; las líneas se
administran exclusivamente desde el canvas.

## Modelo para la siguiente fase

La categoría será la clave para declarar capacidades específicas. Modelo
previsto:

```js
const CATEGORY_CAPABILITIES = {
  "Facebook Page": ["title", "color", "subColor", "iconImage"],
  "Landing Page": ["title", "color", "iconImage", "previewImage"],
  "Almacenamiento SQL": ["title", "color", "iconImage"],
};
```

Esta matriz todavía no restringe controles; sólo se documenta como siguiente
paso. En la implementación actual no se retiró ninguna modificación disponible.
